# Как выложить демо в интернет с телефона

Нужен Node.js 22.5 или новее. Базы и пакетов ставить не надо: `npm install` ничего не скачивает.
Хостинг должен держать WebSocket и работать с Node 22. Подходит Render (бесплатный тариф, засыпает после 15 минут без запросов, первый заход после сна занимает около минуты: **откройте ссылку за пять минут до показа**).

## Render, шаг за шагом (браузер телефона)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (кнопка «+», New repository), назовите `group-order`, тип Public.
2. Загрузите файлы проекта: распакуйте `group-order-v2.zip` (приложение «Файлы»), в репозитории нажмите «Add file → Upload files» и выберите **содержимое** папки (`server.js`, `package.json`, `lib`, `public`, `schema.sql` и остальное), затем «Commit changes». Папки `lib` и `public` загружайте вместе с файлами внутри. На телефоне это проще из мобильной версии сайта в режиме «Версия для компьютера».
3. Откройте render.com, войдите через GitHub: **New → Web Service**, выберите репозиторий `group-order`.
4. Заполните:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance type: **Free**
5. В разделе **Environment** добавьте переменные:
   - `NODE_VERSION` = `22`
   - `TRUST_PROXY` = `1`
   - `DB_FILE` = `:memory:` (бесплатный тариф не хранит файлы; данные пропадут при перезапуске, для демо это нормально)
   - `ADMIN_KEY` = придуманный вами пароль (закрывает настройку меню)
   - `STATS_KEY` = другой пароль (закрывает страницу итогов)
6. Нажмите **Create Web Service**. Через 2–3 минуты вверху появится адрес вида `https://group-order-xxxx.onrender.com`. Это и есть публичная ссылка.

## Перед встречей

1. Откройте `https://<ваш-адрес>/setup?key=<ADMIN_KEY>`, впишите название заведения владельца, доставку, сервисный сбор и меню (одно блюдо в строке: `Категория | Название | Цена | Описание | Вес`), нажмите «Применить».
2. Откройте `https://<ваш-адрес>/` и проверьте меню. Для совместного заказа нажмите «Заказать компанией», QR откройте со второго телефона.
3. Итоги после теста: `https://<ваш-адрес>/stats?key=<STATS_KEY>`.

**Важно:** при перезапуске сервиса меню возвращается к демо-варианту (из-за `:memory:`), поэтому настройку `/setup` делайте перед каждым показом и после «пробуждения» сервиса.

## Альтернативы

- **Railway** (после пробного кредита платный): New Project → Deploy from GitHub repo, те же переменные во вкладке Variables, `Settings → Networking → Generate Domain`.
- **Glitch** закрыл бесплатный хостинг проектов, поэтому его брать не стоит.

## Виджет для сайтов ресторанов и заказы в Telegram

1. Переменные окружения на хостинге: `TG_BOT_TOKEN` (токен от @BotFather), `ADMIN_KEY`, `STATS_KEY`.
   `DB_FILE` либо не задавайте (на Amvera при подключённом хранилище `/data` база ляжет туда сама),
   либо укажите `/data/group-order.db`. Значение `:memory:` стирает данные при каждом перезапуске.
2. Откройте `/setup?key=<ADMIN_KEY>`: название, меню, сайты ресторана (домены, где разрешён виджет), «Применить».
   Страница покажет ключ ресторана и готовую строку для сайта:
   `<script src="https://ваш-домен/w.js" data-key="КЛЮЧ" defer></script>`
3. Ресторан открывает бота и пишет `/start КЛЮЧ`: чат привязан, заказы приходят туда с пометкой «Совместный заказ».
4. Если с хостинга недоступен api.telegram.org, задайте `TG_API_BASE` (адрес прокси).
5. Проверка в браузере без сторонних сайтов: `node scripts/widget-smoke.js`.

### Режим «только корзина» (по умолчанию) и пробный период
Если Telegram ресторана не привязан, виджет не собирает телефон и адрес: после блокировки хост видит «Заказ собран»
с текстом для копирования и оформляет заказ у ресторана как обычно. В `/setup` поле «Пробный период, дней»:
после срока кнопка на сайте исчезает, новые корзины не создаются, пока вы не примените настройку заново.

Отвязать Telegram: написать боту `/stop КЛЮЧ`. Виджет вернётся в режим «только корзина» (телефон и адрес не запрашиваются).

### Каналы ресторана для «Заказ собран»
В `/setup` необязательные поля: WhatsApp (номер с кодом страны), Telegram (логин), телефон. На экране «Заказ собран»
появляются кнопки; текст с адресом собирается на телефоне хоста и уходит из его мессенджера напрямую ресторану,
адрес хранится только в его браузере. Если текст слишком длинный для ссылки, остаются «Позвонить» и «Скопировать».
