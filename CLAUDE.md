# CLAUDE.md — «Общий заказ»

## Стек и окружение
- Runtime: Node.js (`server.js`), без тяжёлых фреймворков.
- Модули: `lib/db.js`, `lib/hub.js`, `lib/notify.js`, `lib/service.js`, `lib/ws.js`.
- БД: SQLite (`data/group-order.db`, схема `schema.sql`), размещена на сервере Amvera в РФ.
- Клиент и виджет: Vanilla JS, HTML, CSS (`public/app.js`, `public/app.html`, `public/app.css`, `public/w.js`, `public/qr.js`).
- Деплой: автоматический на Amvera при push/merge в основную ветку.

## Правила экономии токенов и работы
1. Читай ТОЛЬКО те файлы, которые напрямую относятся к текущей задаче. Не сканируй весь репозиторий и не читай `test/` или `data/group-order.db`, если задача этого не требует.
2. Делай минимальные, точечные и безопасные изменения без рефакторинга несвязанного кода.
3. Не ломай существующую схему и данные в `data/group-order.db` — при изменении схемы/запросов делай аккуратную проверку/миграцию.
4. Соблюдай 152-ФЗ: не логируй персональные данные (имена, телефоны) в консоль/логи продакшена; поддерживай автоочистку/обезличивание телефонов участников через 24 часа после закрытия заказа.
5. В конце дай краткий список изменённых файлов и шаги проверки на Amvera.
